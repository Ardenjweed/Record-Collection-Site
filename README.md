# My Recorcd Collection Site
This is site to display my vinyl record collection. This was a project that I used to learn Angular for the first time.

If you wish to view this site locally with full functionality go to the main branch.

This is the vercel branch where the serverless functions in /api were created.

## Tech Stack
Front-End: Angular, Angular-Material

Back-End: Node/Express.js

API's: 
- Discogs for album track listing information
- Deezer for 30s track preview
